# Figure Evidence Review — Backend

**Reviewed:** 2026-11-02
**Scope:** Backend data paths, API behavior, and calculation evidence for the twelve proposed system figures. This is a source review, not a live API/database validation. No production dataset was available for independent reproduction.

The frontend screen and caption evidence is documented separately in [`espasyo/FIGURE_EVIDENCE.md`](../espasyo/FIGURE_EVIDENCE.md).

## Assessment terms

- **Present:** A corresponding endpoint, calculation, or data path exists in source.
- **Partial / caption correction needed:** Related backend behavior exists, but it does not support all claims in the proposed caption.
- **Not present as described:** No corresponding backend calculation or output was found in the inspected code.
- **Not verified:** Source code alone cannot establish production configuration, data provenance, live results, or predictive accuracy.

## Evidence needed beyond source inspection

For a complete figure proof package, preserve (with sensitive fields redacted) the request parameters, selected filters, API request/response, analysis or forecast run identifier, and the underlying input extract. Recompute displayed aggregates from that extract and compare them to the returned values. For geocoding, independently verify sample coordinates. For security, execute unauthenticated and authenticated requests against every sensitive endpoint. For forecasting, use a reproducible held-out real-data evaluation and baseline; a code path or screenshot alone does not establish predictive validity.
